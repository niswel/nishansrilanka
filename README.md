# NishanSriLanka.com — V2

Lightweight static website for Nishan, an SLTDA-licensed Tourist Driver in Sri Lanka.

## Included
- Pure HTML + CSS + JavaScript — no WordPress, database, PHP or build system.
- 8 working language options: English, German, French, Spanish, Italian, Tamil, Malay and Japanese.
- Four genuine Google reviews supplied by the owner. The Norwegian review is displayed as an English translation and labelled accordingly.
- Owner portrait, real vehicle photographs and selected Sri Lankan photographs supplied by the owner.
- Responsive desktop/tablet/mobile layout.
- SEO metadata, Open Graph, Twitter metadata, robots.txt and sitemap.xml.
- Person + Service structured data.
- WhatsApp and telephone CTAs.
- Formspree contact form placeholder.

## Before launch
1. Create a Formspree form and replace `YOUR_FORM_ID` in `index.html`.
2. Test the contact form and spam protection.
3. Test all eight language options.
4. Test WhatsApp and phone links on mobile.
5. Confirm the four Google reviews against the live Google profile.
6. Upload to GitHub and deploy through Cloudflare Pages.
7. Connect `nishansrilanka.com`.
8. Add/verify the website in Google Search Console and submit `sitemap.xml`.

## Terminology
The site uses **SLTDA-licensed Tourist Driver**. It does not position Nishan as a licensed chauffeur or licensed tourist guide.
