# NishanSriLanka.com — Production V5

Lightweight static website for Nishan, an SLTDA-licensed Tourist Driver in Sri Lanka.

## Stack
- Pure HTML + CSS + JavaScript
- Cloudflare Pages
- Formspree contact form
- Cloudflare Turnstile spam protection
- No WordPress, database, PHP, framework or build system

## Production setup
- Canonical site: https://nishansrilanka.com/
- Formspree endpoint: https://formspree.io/f/xdeondlr
- Cloudflare Turnstile: configured for nishansrilanka.com
- Google Business Profile website: https://nishansrilanka.com/

## Website positioning
Nishan is presented as an SLTDA-licensed Tourist Driver. The site does not describe him as a licensed chauffeur or licensed tourist guide. SunSpire Holidays is a separate business for fully arranged holidays.

The language selector provides visitor-facing translations. It does not make claims about Nishan’s personally spoken languages.

## Deployment
Cloudflare Pages is connected to this repository. Replace the site files with this V5 package, commit to the main branch, and allow Cloudflare Pages to deploy automatically.
